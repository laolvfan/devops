# 决策记录

选择保留教师算法，增加边界测试与独立实验输入。E8 拒绝未知目标；E9 验证变量改名仍只修改定义并保留引用；E10 用能构建但仍有 MD 的补丁验证接受门禁。三者分别具有写入保护、声明风格和行为正确性的明确预期。

没有把编译成功作为唯一接受标准；通过 Patch 应用、构建、功能、头文件变化和依赖重检后才允许写回。相比直接修改源项目，验证副本有复制与重建成本，但能在拒绝时保持源字节，也保留可检查的 sandbox 日志。

共享变量被多目标引用时，修改定义可能扩大影响；本次只验证单目标纯变量及变量名变化，不声称消除了该限制。隐式 Make 规则、复杂变量和未支持配置保持教学范围，不做未经验证的泛化。

验证：个人镜像中 10 项测试通过；各阶段分步日志全为退出 0；E10 三种基线场景及剩余 MD 扩展均符合独立预期。具体输入、命令和路径见个人报告及运行汇总。
